EarphoneNap

イヤホン前提で使える、仮眠向けアラーム・タイマー

EarphoneNap は、イヤホン利用を前提にした、昼寝や短時間休憩向けのアラーム・タイマーアプリです。周囲に大きな音を出さず、静かな環境でも使いやすい目覚まし体験に絞って設計されています。

アプリ概要

一般的な多機能アラームではなく、短時間の仮眠や休憩を快適に終えることに特化したアプリです。「何時に起きるか」「何分だけ寝るか」をすばやく設定できます。

利用シーン

昼休みの仮眠、通勤・通学中の短時間休憩、カフェや共有空間での静かな目覚まし、作業の合間のパワーナップに向いています。

対応環境

iOS 17.0以降の iPhone 向けアプリです。Live Activity と Dynamic Island の表示可否は端末やOS条件に依存します。

主な特長

イヤホン利用を前提に、短時間休憩をすばやく管理できる機能に絞っています。

時間設定

  • 指定時刻に鳴らすアラーム機能
  • 何時間何分何秒後に鳴らすタイマー機能
  • 鳴動中に指定分数だけ延長できるスヌーズ機能
  • 一時停止、再開、キャンセルに対応

通知と表示

  • イヤホン接続時はイヤホン側で通知音を鳴らす設計
  • 音、バイブレーション、フェードインを調整可能
  • Live Activity と Dynamic Island で進行状況を確認可能
  • 日本語、英語、システム設定に応じた表示言語に対応

イヤホンまわりの仕様

  • 有線イヤホン、Bluetooth、USB Audio などの接続状態を監視します。
  • イヤホン未接続で音ありのサウンドを選んでいる場合、音が再生されないケースがあります。
  • バイブレーションが有効なら、音が鳴らない場合でもバイブで通知できます。
  • 鳴動中にイヤホンが外れたときの挙動を選べます。
  • 一度切断されたあと、再接続しても音が自動再開しない安全設計です。

設定できる内容

  • アラーム時刻、タイマー時間、スヌーズ時間
  • 通知音、バイブレーション、音量、音量フェードイン
  • イヤホン切断時の動作
  • イヤホン接続ステータス表示
  • Bluetooth不安定時の警告表示
  • アプリ表示言語

無料版と Premium

無料版には広告が表示されます。バナー広告に加え、アラーム終了後にインタースティシャル広告が表示される場合があります。

EarphoneNap Premium は買い切り型の非消耗型アプリ内購入で、サブスクリプションではありません。Premium により広告非表示と追加サウンドが解放されます。なお、Premium は購入時点で提供されている内容を対象とするもので、将来の機能追加、サウンド追加、仕様変更、アップデートの提供を保証するものではありません。

利用できるサウンド

無料サウンド

  • Gentle
  • Chime
  • Bell
  • Vibration Only

Premiumサウンドの例

  • Acoustic Guitar、Breeze、Flute、Harp
  • Kalimba、Music Box、Ukulele、Vibraphone など

注意事項

本アプリはイヤホン利用を前提にしたアプリです。イヤホン、端末状態、iOS、Bluetooth、通知、音量、省電力設定などの状態により動作が影響される場合があります。重要な予定、生命・身体・財産に関わる用途など、失敗すると重大な影響がある場面では使用しないでください。
